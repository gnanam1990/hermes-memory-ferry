The problem

Copying memory is easy.
Proving what happened is not.

A manual migration loses source locations, silently duplicates records, and gives an operator no defensible answer when retrieval changes or rollback removes the wrong thing.

Provenance collapses

Source file, section, line span, mtime, and content hash disappear in copy/paste.

Retries create drift

A timeout makes it unclear whether to retry, reconcile, or risk a second write.

Success is assumed

Row counts cannot prove that the destination still returns the memories users need.

The control loop

One migration. Seven explicit gates.

Every step emits evidence from the same local journal. Nothing depends on a hosted control plane, API key, or remote worker.

  1. 01
    Preflight

    Verify readable sources and destination readiness.

  2. 02
    Plan

    Export canonical JSONL and classify every record.

  3. 03
    Approve

    Bind the exact source, policy, decisions, and destination.

  4. 04
    Run

    Journal intent before mutation and reconcile interrupted work.

  5. 05
    Verify

    Measure deterministic retrieval overlap, never just row counts.

  6. 06
    Report

    Generate a standalone, content-free evidence UI.

  7. 07
    Rollback

    Remove only records with exact migration ownership proof.

Honest boundary

Narrow enough to be real.

Version 0.1.0 supports one production-shaped route: Hermes built-in MEMORY.md and USER.md into Memory Ferry's local SQLite provider. Arbitrary third-party provider migration is not implemented or claimed.

Security properties

  • No credentials or telemetry
  • No network calls or subprocesses
  • Secret-like records blocked by default
  • Exact-plan integrity checked before writes
  • Rollback requires ownership proof
